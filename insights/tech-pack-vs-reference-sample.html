Tech pack vs. reference sample: what do you need?

A tech pack and a reference sample both help explain an apparel product, but they serve different purposes. Understanding the difference can help buyers start a sourcing conversation with the right expectations.

A tech pack and a reference sample both help explain an apparel product, but they serve different purposes. Understanding the difference can help buyers start a sourcing conversation with the right expectations.

A tech pack explains the product. A reference sample shows the product. Together, they make the sourcing conversation stronger.

What is a tech pack?

A tech pack is a technical product document that explains how a garment should be made. It may include measurements, grading, construction details, fabric specifications, trims, labels, colors, artwork, packaging, and fit notes.

For developed products, a tech pack can make the sourcing conversation much more precise. It gives the supplier or sourcing team a clearer reference point and reduces ambiguity.

What is a reference sample?

A reference sample is a physical product or visual example that communicates the style, fabric, fit, or construction direction. It may be an existing garment, a competitor sample, a store-bought item, or a prior version of the buyer’s product.

Reference samples are useful when the buyer does not yet have full technical specifications. They help show what the buyer means, especially when describing fit, fabric feel, silhouette, or construction.

When a tech pack is useful

A tech pack is most useful when the buyer already knows exactly what they want to produce. It is especially helpful for private label programs, repeatable styles, detailed construction, custom measurements, or products with multiple colorways and size ranges.

A tech pack also helps when more than one sourcing option is being evaluated because it gives everyone the same information to review.

When a reference sample is enough to start

A reference sample may be enough to begin when the buyer is still exploring product direction or wants to understand whether an opportunity is worth developing further.

Photos, links, and samples can help start the conversation, but additional details may be needed before sampling or production planning can move forward.

The best scenario: use both

When possible, send both a tech pack and a reference sample. The tech pack explains the technical details; the sample shows the real-world look and feel.

Together, they reduce interpretation gaps and help the sourcing conversation become more accurate.

What to do if you have neither

If you do not have a tech pack or sample, start with photos, sketches, inspiration links, and a clear explanation of the product. The first step may be to organize the product direction before requesting a detailed sourcing review.

Key takeaways

  • A tech pack is a technical document; a reference sample is a visual or physical guide.
  • You can often start with a reference sample or photos.
  • For developed products, a tech pack improves accuracy.
  • If you have both, send both.
