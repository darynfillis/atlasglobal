Tech pack vs. reference sample: what do you need?

A tech pack and a reference sample both help explain an apparel product, but they are not the same. Each one plays a different role in the sourcing process.

Start with What You Have Back to Insights

What is a tech pack?

A tech pack is a detailed product document. It may include measurements, construction details, fabric information, trims, colors, labels, packaging, and other specifications needed to make the product.

What is a reference sample?

A reference sample is a physical product or visual example that shows the style, fit, fabric, or construction direction you want. It helps communicate the idea even if the technical details are not fully developed.

Which one is better?

A tech pack is usually better when the product is developed and ready for detailed review. A reference sample is useful when the product direction is still being shaped.

Can you start without a tech pack?

Yes. Many sourcing conversations can start with photos, reference samples, and a clear product description. The team can help identify what details are still needed.

Best practice

If you have both a tech pack and a reference sample, send both. The more clearly the product is communicated, the easier it is to evaluate the opportunity.
